# Журнал изменений

## Первый русский пакет — подготовка

- Уточнена документация: первая сборка не заменяет анкету непроверенным HTML override.
- Удаляется `patches/ru/assets/overrides/questionnaire.html` из набора патчей; оригинальный asset внутри APK не меняется.
- Сохранён scope патча: Android-ресурсы и только проверенные текстовые assets; DEX, native libraries и manifest не изменяются скриптами патча.
- Добавлен файл состояния проекта с эталонным SHA-256, согласованным решением и ограничениями проверки.

Проверка сборки и runtime ещё не выполнена в рамках этого изменения; результат будет определён по GitHub Actions и артефактам после пользовательской передачи.
