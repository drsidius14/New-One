# Xiaomi Health Research 1.4.6 — Russian patch project

Проект русификации **только одного исходного APK**: `app/base/小米健康研究_1.4.6.apk`.

## Зафиксированная база

- Имя: `小米健康研究_1.4.6.apk`
- Package: `com.mi.healthresearch`
- Версия: `1.4.6` (version code `1004006`)
- SHA-256: `9e872f2d75e4ec1d509216d8caa998c2957d797c57b8ecc1ed8c92054f53c4bc`
- Сертификат подписи исходника (SHA-256): `9cb6462cd31547c823763ee8ca30d35ad448f4034412cf6e6ee77dfb5293df1d`

Перед анализом и сборкой `scripts/verify_source.py` сверяет SHA-256. Несовпадение останавливает pipeline: другой APK использовать нельзя.

## Состав первой русифицированной сборки

- существующий патч строк Android в `patches/ru/resources.json`;
- извлечение фактического каталога строк и текстовых assets для последующего расширения перевода;
- проверки идентичности APK, ключей ресурсов и форматных плейсхолдеров;
- GitHub Actions для декодирования, аудита и сборки после применения патчей;
- тесты скриптов.

**Анкета `assets/questionnaire.html` намеренно не переопределяется в первом пакете.** Ранее подготовленный override содержал заглушку и несогласованные обращения JavaScript к элементам формы. До сравнения с оригинальным файлом APK он исключается, чтобы не затереть возможную рабочую реализацию. Сам исходный APK и оригинальный asset не изменяются.

Это стартовый патч, а не завершённая русификация всего приложения. Строки основного Android-интерфейса расширяются только по фактическому каталогу ресурсов конкретного APK.

## Структура

```text
app/base/                     единственная неизменяемая база APK
config/project.json           версия, package, ожидаемый SHA-256
patches/ru/resources.json     русские ресурсы Android по ключам
patches/ru/assets/overrides/  только проверенные переводы текстовых assets
scripts/                      проверка, извлечение каталога, применение патчей
tests/                        модульные тесты
.github/workflows/            автоматическая проверка и сборка
```

## После передачи изменений

Проверьте GitHub Actions → `Mi Health Research 1.4.6 — Russian patch`. Ожидаемый первый артефакт каталога — `mi-health-research-1.4.6-ru-catalog`. Успешная сборка APK, если она появится, сама по себе не доказывает установку, запуск или сохранность всех интеграций.

## Ограничения подписи

Пересобранный APK подписывается ключом проекта/CI, отличным от Xiaomi. Возможность обновления поверх оригинальной установки не гарантируется. Стабильность ключа проекта должна контролироваться конфигурацией CI; секреты и keystore нельзя хранить в открытом репозитории.

APK в каталоге проекта остаётся проприетарным материалом Xiaomi; прежде чем распространять APK, проверьте право на распространение.
