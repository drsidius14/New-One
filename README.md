# Xiaomi Health Research 1.4.6 — Russian patch project

Проект русификации **только одного исходного APK**: `app/base/小米健康研究_1.4.6.apk`.

## Зафиксированная база

- Имя: `小米健康研究_1.4.6.apk`
- Package: `com.mi.healthresearch`
- Версия: `1.4.6` (version code `1004006`)
- SHA-256: `9e872f2d75e4ec1d509216d8caa998c2957d797c57b8ecc1ed8c92054f53c4bc`
- Сертификат подписи исходника (SHA-256): `9cb6462cd31547c823763ee8ca30d35ad448f4034412cf6e6ee77dfb5293df1d`

Перед анализом и сборкой `scripts/verify_source.py` сверяет SHA-256. Несовпадение останавливает pipeline: другой APK использовать нельзя.

## Что уже подготовлено

- точный исходный APK;
- патч видимого текста `assets/questionnaire.html` на русский;
- схема для строк, массивов строк и множественных форм в `patches/ru/resources.json`;
- проверки идентичности APK, ключей ресурсов и форматных плейсхолдеров;
- извлечение JSON/CSV-каталогов строк и текстовых assets;
- GitHub Actions для декодирования, аудита и сборки APK после появления патчей;
- тесты скриптов.

**Важно:** это стартовый патч, а не завершённая русификация всего приложения. Строки основного Android-интерфейса не заполняются догадками: первый запуск workflow создаст каталог фактических ресурсов этого APK, после чего их можно переводить по ключам.

## Структура

```text
app/base/                     единственная неизменяемая база APK
config/project.json           версия, package, ожидаемый SHA-256
patches/ru/resources.json     русские ресурсы Android по ключам
patches/ru/assets/overrides/  переводы текстовых assets по исходному пути
scripts/                      проверка, извлечение каталога, применение патчей
 tests/                       модульные тесты
.github/workflows/            автоматическая проверка и сборка
```

## После отправки в GitHub

Workflow `Mi Health Research 1.4.6 — Russian patch` запустится после push. Он проверит SHA-256, выполнит тесты, скачает закреплённый Apktool 3.0.3 с проверкой его SHA-256, декодирует приложение и загрузит артефакт с CSV/JSON-каталогами переводимых ресурсов. При наличии патчей дополнительно соберёт и подпишет тестовый APK.

Откройте **Actions → Mi Health Research 1.4.6 — Russian patch**. Каталоги будут в артефакте `mi-health-research-1.4.6-ru-catalog`.

## Ограничения подписи

APK после пересборки подписывается временным CI-ключом для тестирования. Он не является обновлением, подписанным Xiaomi, и обычно не установится поверх исходной Xiaomi-версии без удаления оригинала. Не используйте такой APK для медицинских/исследовательских решений без собственной проверки.

APK в каталоге проекта остаётся проприетарным материалом Xiaomi; прежде чем делать репозиторий публичным или распространять APK, проверьте право на распространение.
