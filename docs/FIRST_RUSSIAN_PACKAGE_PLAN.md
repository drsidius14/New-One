# План и критерии приёмки первого русского пакета

## Решение

Первая русифицированная сборка ограничивается существующими Android-ресурсами из `patches/ru/resources.json`. `patches/ru/assets/overrides/questionnaire.html` исключается из набора патчей до прямого сравнения с исходным файлом внутри эталонного APK.

## Причина

В текущем override обнаружены заглушка анкеты, пустая форма и JavaScript, обращающийся к отсутствующему `confirmButton`. Замена целого исходного файла может уничтожить функциональность, которой нет в override. Поэтому безопаснее не применять его, чем угадывать исходную реализацию.

## Инварианты

- Эталонный APK и его SHA-256 не изменяются.
- Не изменяются package name, версия, manifest, DEX, native libraries, permissions, provider authorities и intent actions.
- Ключи ресурсов, плейсхолдеры, HTML/URL-ссылки и форматные строки должны сохраняться.
- Mi Fitness 3.59.1 используется только как источник контекста интеграционного аудита, не как целевой APK.
- Не включать секреты или keystore в репозиторий/ZIP.

## Проверки после push

1. Проверить, что коммит содержит только согласованные изменения и удаление HTML override.
2. Проверить завершение workflow и тестов.
3. Скачать/проверить наличие каталога `mi-health-research-1.4.6-ru-catalog`.
4. Проверить число извлечённых Android-ресурсов и текстовых assets; исследовать CSV/JSON каталог, затем расширять перевод по фактическим ключам.
5. Если workflow собрал APK — проверить артефакт, подпись и ZIP integrity отдельно.
6. Установку, запуск и обмен данными с Mi Fitness отмечать как непроверенные, пока не получены реальные результаты на устройстве.
