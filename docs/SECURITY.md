# Безопасность

- Анализируйте APK, которые вы вправе исследовать и модифицировать.
- Не запускайте извлечённые бинарники/скрипты и не устанавливайте неизвестный APK на основное устройство без проверки.
- Не коммитьте подписи, ключи, пароли, токены, cookies, дампы авторизации или персональные данные.
- CI не использует production-ключи и не подписывает APK автоматически.
- Скачивание выполняется по HTTPS из официальных проектов; для критичных релизов проверяйте контрольные суммы и подписи поставщика.
