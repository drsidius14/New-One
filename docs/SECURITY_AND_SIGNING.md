# Безопасность и подпись

- Исходный APK проверяется SHA-256 до декомпиляции.
- Инструмент Apktool закреплён на версии 3.0.3 и проверяется собственной SHA-256 суммой релиза.
- CI создаёт временный тестовый keystore только на runner; пароли и ключи не попадают в репозиторий или artifacts.
- Для тестового APK сертификат отличается от Xiaomi. Он не сможет обновить оригинальное приложение без удаления оригинала, а удаление может стереть локальные данные.
- Не коммитьте персональный keystore, пароль, токены или приватные данные.
- Публикация APK третьей стороны может требовать разрешения правообладателя.
