# Инструменты и официальные источники

| Инструмент | Назначение | Источник |
|---|---|---|
| Apktool | декодирование/сборка ресурсов | https://github.com/iBotPeaches/Apktool |
| JADX | декомпиляция кода | https://github.com/skylot/jadx |
| Android SDK command-line tools | sdkmanager / avdmanager | https://developer.android.com/studio#command-line-tools-only |
| Platform Tools | adb / fastboot | https://developer.android.com/tools/releases/platform-tools |
| Build Tools | aapt2 / zipalign / apksigner | https://developer.android.com/tools/releases/build-tools |
| Android Emulator | виртуальное устройство | https://developer.android.com/studio/run/emulator |
| OpenJDK | среда Java | https://adoptium.net/ |

Дополнительно по необходимости: Bundletool (AAB/split APK), MobSF (изолированный статический/динамический анализ), Appium/UIAutomator (повторяемые UI-тесты). Не устанавливаем всё подряд до выяснения требований конкретного APK.
