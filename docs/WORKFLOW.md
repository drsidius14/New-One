# Рабочий процесс

1. **Инвентаризация:** сохранить оригинал локально, вычислить SHA-256, проверить package name, version, min/target SDK и ABI.
2. **Декомпиляция:** Apktool — ресурсы и манифест; JADX — навигация по коду. Декомпиляция не восстанавливает исходники один-в-один.
3. **Перевод:** сравнить `res/values/strings.xml` и имеющиеся каталоги `values-zh*`. Не менять строки массово без контекста.
4. **Проверки:** XML, плейсхолдеры (`%1$s`, `%d`), HTML/escape-последовательности, ссылки на ресурсы, оставшиеся китайские символы.
5. **Сборка:** `apktool b`; исправлять конкретные ошибки, не удалять ресурсы наугад.
6. **Выравнивание и подпись:** `zipalign` до `apksigner`; затем `apksigner verify --verbose --print-certs`.
7. **Установка:** `adb install -r` на совместимое устройство/эмулятор; при сбое сохранить `adb logcat`.
8. **Регрессия:** авторизация, разрешения, навигация, сеть, локализация, установка/обновление.

## ABI
`arm64-v8a` — 64-битный ARM ABI. Эмуляторный образ ARM64 и ABI самого APK — разные вещи. Проверяйте наличие `lib/arm64-v8a/` и требования зависимостей.

## Git
Не хранить в репозитории APK без разрешения, keystore, токены, пароли, cookies, приватные конфигурации и дампы с персональными данными.
