# Русская локализация

Здесь хранятся глоссарии и переводческие заметки, но не исходный APK.

- Сохраняйте форматные плейсхолдеры (`%1$s`, `%2$d`, `%%`).
- Сохраняйте HTML-теги, escape-последовательности и Android string markup.
- Проверяйте длину строк на узких экранах.
- Отличайте текст интерфейса от брендов, идентификаторов, URL и диагностических сообщений.
- Найденные китайские символы перепроверяйте вручную.
